# @hius/shared

[English](README.md)

Shared Kernel — общие типы value-object и утилиты, от которых может
зависеть любой домен, **без бизнес-логики и без доменно-специфичных
экспортов**. Любой домен может импортировать из `shared`, не декларируя
это в `allowedDependencies` (разрешено неявно); сам `shared` не может
зависеть ни от одного домена, и валидатор границ отклоняет экспорт, чьё
имя ссылается на конкретный домен (`BillingInvoiceFormatter` в `shared` —
ошибка валидатора именно по этой причине).

**Текущий статус: заглушка.** Пакет существует и подключён в workspace,
но в него пока ничего не добавлено — в самом фреймворке ещё не возникло
конкретного междоменного типа, который требовалось бы сюда вынести. Как
только у приложения на Hius появится реальный value object, общий для
двух и более доменов (`Money`, тип адреса и подобное), — ему место здесь.

Как правила `shared` не просто документированы, а обеспечиваются
валидатором — см. [Архитектуру](../../docs/ru/architecture.md#намерение-и-факт).
