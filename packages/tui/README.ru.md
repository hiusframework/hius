# @hius/tui

[English](README.md)

Многоокружный терминальный дашборд — `hius tui` (из
[`@hius/cli`](../cli/README.ru.md)). В духе zellij, не tmux/k9s (D16,
решено в плановой документации фреймворка): по вкладке на окружение,
внутри вкладки одновременно видны три панели (консоль, БД, логи),
плавающая командная палитра и всегда видимая строка быстрого ввода.
Опциональный — проект, который ни разу не запускает `hius tui`, никогда
не тянет зависимость этого пакета от [`@opentui/core`](https://github.com/anomalyco/opentui).

## Скоуп v1: только локальные окружения

`dev` и `test` — оба работают как дочерние процессы на этой же машине, с
console/db-контекстом, построенным так же, как его строят `hius
console`/`hius db`. Переключение на `staging`/`production`, живущие на
удалённом хосте, требует SSH-реализации `Target`, которой в этом пакете
пока нет — ничто здесь не мешает добавить её позже без переписывания
(`Target` уже и есть тот самый шов), но она не построена.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `←` / `→` (фокус на панели вкладок) | Переключить окружение |
| `Tab` | Циклический фокус: панель вкладок → консоль → БД → быстрый ввод → панель вкладок |
| `Ctrl+K` | Открыть командную палитру (fuzzy-search) |
| `Escape` | Закрыть палитру |
| `Enter` (панель консоли/БД) | Выполнить строку |
| `Enter` (строка быстрого ввода) | Запустить `<id команды> [аргументы...]` |

Никакого toggle на `Ctrl+J` для строки быстрого ввода — сознательно:
`Ctrl+J` (`0x0A`) в обычном терминале — тот же самый байт, что и перевод
строки, поэтому надёжно отличить его от Enter нельзя. Строка быстрого
ввода вместо этого просто всегда часть layout'а (и так ближе к строке
ввода, по образцу которой она сделана).

## Команды и плагины

```ts
import { definePlugin } from "@hius/tui";

const myPlugin = definePlugin({
  name: "demo",
  commands: [
    {
      id: "hello",
      label: "Say hello",
      description: "Печатает приветствие в панель логов",
      run: (ctx) => ctx.target.run(["echo", "hello from a plugin"]),
    },
  ],
});
```

Зарегистрированные команды появляются с namespace-префиксом
(`demo:hello`) и в строке быстрого ввода, и в командной палитре — один
`CommandRegistry`, два способа до него добраться: набрать id напрямую
или открыть палитру (`Ctrl+K`) и найти по label/description через
fuzzy-search. `run` команды получает текущий `Target` (консоль/БД/
процесс активного окружения) и `switchEnvironment` — те же примитивы,
которыми пользуются встроенные `server:start`/`server:stop`/`run`/`env`.

## Запуск

```bash
hius tui [--dir domains]
```

`DATABASE_URL` для `dev` читается из `.env` (или текущего окружения
процесса), для `test` — из `.env.test`, читается напрямую, а не через
собственную однофайловую загрузку окружения Bun — та не может держать
значения двух окружений живыми в одном процессе одновременно.
